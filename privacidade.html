Política de Privacidade

Última atualização: 9 de outubro de 2026.

O que o aplicativo acessa

Com a autorização do próprio usuário, o mailbox-mcp usa a API do Gmail com os escopos gmail.modify, gmail.compose e gmail.settings.basic. Isso permite ler, pesquisar, organizar (marcadores, arquivar, lixeira), redigir e enviar mensagens, e gerenciar filtros, assinatura, resposta automática e endereços de envio da conta do usuário.

Onde os dados ficam

O aplicativo roda apenas no computador do usuário. As credenciais de acesso (tokens) são guardadas localmente, em arquivos do próprio usuário. Não existe servidor do desenvolvedor: nenhum dado do Gmail é enviado, armazenado, vendido ou compartilhado com o desenvolvedor ou com terceiros por este aplicativo.

Cliente de IA escolhido pelo usuário

O conteúdo consultado pelo aplicativo é entregue ao cliente MCP que o próprio usuário usa (por exemplo, um assistente de IA). Se esse cliente processar o conteúdo em nuvem, o tratamento passa a seguir os termos e a política do provedor escolhido pelo usuário. O mailbox-mcp não usa dados do Gmail para publicidade nem para treinar modelos.

Uso limitado

O uso e a transferência, pelo mailbox-mcp, das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Retenção e revogação

Os dados locais permanecem até o usuário remover a conta no aplicativo ou apagar os arquivos. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
